# Publishing, previewing and scheduling

## The status of a page

| Status                   | Meaning                                                    |
| ------------------------ | ---------------------------------------------------------- |
| **Draft**                | Only staff can see it.                                     |
| **Waiting for approval** | Sent to an approver (only when your school uses approval). |
| **Scheduled**            | Goes on the website by itself at the time you chose.       |
| **On website**           | Visitors can see it.                                       |

## The buttons

| Button                 | What it does                                                                                                                                                                                                             |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Save draft**         | Saves the page without publishing it.                                                                                                                                                                                    |
| **Preview**            | Opens the page in a new tab exactly as visitors would see it, with your latest changes. A dark bar at the top says **Preview — not published**. Visitors can't see a preview. Select **Exit preview** when you are done. |
| **Publish to website** | Puts the page on the website now.                                                                                                                                                                                        |
| **Publish changes**    | For a page already on the website: puts your saved changes live.                                                                                                                                                         |
| **Schedule…**          | Choose a date and time (in your school's time zone). The page goes live then, even if nobody is logged in. It may take up to five minutes after the time.                                                                |
| **Cancel schedule**    | Keeps the page as a draft.                                                                                                                                                                                               |
| **Hide from website**  | Takes the page off the website. You can publish it again at any time.                                                                                                                                                    |
| **Move to Trash**      | See `trash.md`.                                                                                                                                                                                                          |

You only see the buttons you are allowed to use.

## When two people edit the same page

- If someone else is editing the same page, the editor says so, for example "**Sarah Namu is also editing this page**". Agree who will publish.
- If someone else publishes first, your next publish is stopped with: "**Someone else edited this — reload to see their changes.**" Nothing you typed is lost.
- After reloading you see their version, and a message: "**You have unsaved changes from before someone else changed this page**". Select **Show my changes** to bring your text back, check it against theirs, then publish. Or select **Discard them**.

## Approval (if your school uses it)

Your school can switch on **approval**: then only an approver (for example the Headteacher) can publish.

- If you can't publish, you see **Submit for approval** instead of **Publish to website**.
- Approvers see "**N pages waiting for your approval**" on the Overview. They can **Publish to website**, **Schedule…**, or **Send back…** with a note saying what needs changing.
- When a page is sent back, the author sees the note at the top of the page until they submit it again.
