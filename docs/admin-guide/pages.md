# Website pages

Pages are the parts of the website that don't change often: "About the school", "Fees", "Uniform", "School rules". Open **Website pages** in the menu on the left.

## Add a page

1. Select **New page**.
2. Type the title, for example "School fees 2027".
3. Under **Where it sits**, choose **At the top level**, or a page it belongs inside (for example inside "Admissions").
4. Select **Create and edit**.

The new page is a **draft**: nobody outside the school can see it until you publish it (see `publishing.md`).

## Write the page

- **Page title** is the big heading at the top of the page.
- **Web address** is made from the title, for example `school-fees-2027`. You can change it before publishing. If you change the address of a page that is already on the website, the old address keeps working: visitors are sent to the new one.
- **Page text** is where you write. The toolbar has:
  - **Normal text / Heading / Subheading / Small heading**: use headings to split long pages into sections.
  - **Bold**, **Italic**, **Bulleted list**, **Numbered list**, **Quote** and **Dividing line**.
  - **Add a link**: type a web address like `https://example.org`, or a page on this website like `/admissions`.
  - **Add a photo**: choose a photo from the media library, or upload one. See below.
  - **Link to a PDF**: select some words first, then choose the PDF. The link always opens the current version of the document, and the website shows its size, for example "(PDF, 240 KB)".
  - **Undo** and **Redo**.

### Photos need a description

A photo can't be added until it has a **photo description**: one sentence saying what it shows, for example "Senior two pupils planting trees beside the library". Blind visitors hear it read aloud, and it helps Google. If a photo has no description yet, the system asks for it before adding the photo.

Under each photo in the editor you can choose **Make it full width** or **Remove photo**.

## Page settings

| Setting                             | What it does                                                                      |
| ----------------------------------- | --------------------------------------------------------------------------------- |
| **Where it sits**                   | Which page it belongs inside. Pages can be nested up to three levels deep.        |
| **Layout**                          | Standard, Wide (for tables and large photos), or With a side menu of the section. |
| **Show in its section's side menu** | Lists the page in the side menu of pages that use the "side menu" layout.         |
| **Summary**                         | A sentence or two shown in search results and when the page is shared.            |
| **Cover photo**                     | A large photo at the top of the page (it needs a description too).                |
| **How this page looks on Google**   | Change the title and description Google shows, or hide the page from Google.      |

## Order and nesting

In the **Website pages** list, each page has four buttons:

- **Move up** and **Move down** change the order in the menu.
- **Move into the page above** puts the page inside the page above it.
- **Move out of its section** moves it up one level.

Clear the search and filters to see these buttons. Moving a page that is on the website changes its address; the old address keeps working.

## Built-in pages

Some pages, such as "About the school", are **built in**. You can edit what they say, but you can't move, rename or delete them, because other parts of the website link to them.

## Saving

Your changes are saved automatically as you type. The editor shows:

- **Saving…** while it saves
- **All changes saved** when it has
- **Not saved — check your connection** if the internet dropped. Keep the page open: it tries again by itself.

Saved changes to a page that is already on the website are **not public yet**: they appear when you select **Publish changes**.
