# The Overview (dashboard)

The **Overview** is the first page you see after signing in. It shows what needs doing, not just numbers. Each box opens the list it talks about.

| Box                                         | Who sees it                               | Opens                                   |
| ------------------------------------------- | ----------------------------------------- | --------------------------------------- |
| **N pages waiting for your approval**       | Approvers, when your school uses approval | Website pages, filtered to those pages  |
| **N pages going live in the next 48 hours** | Anyone who can see website pages          | Website pages, filtered to Scheduled    |
| **N drafts not touched for 30 days**        | Anyone who can edit pages                 | Website pages, filtered to Drafts       |
| **N photos need a description**             | Anyone who can edit the media library     | Media library, filtered to those photos |
| **N items in Trash**                        | Anyone who can delete pages or files      | Trash                                   |

Boxes that need someone to act have a coloured edge. When there is nothing to do, the Overview says **All caught up**.

If you can see the activity log, the Overview also lists **recent changes to the website**: who published, hid, scheduled or moved what, and when.

More boxes arrive with each part of the system: applications waiting more than 7 days, new enquiries and the next event.
