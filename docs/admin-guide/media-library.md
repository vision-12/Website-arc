# The media library

The media library holds the **photos** and **PDF documents** used on the website. Open **Media library** in the menu on the left.

## Upload

Drag photos onto the upload box, or select **Choose files**. You can choose several at once.

- Photos are made smaller on your device before they are sent, to save data. A 4 MB phone photo usually becomes about 1 MB.
- iPhone photos are converted to JPG automatically.
- Limits: photos up to **10 MB**, PDFs up to **20 MB**.
- Each file shows its progress: getting ready, uploading (with a percentage), checking, then "Added to the library".
- If something goes wrong, the reason is shown in plain words with a **Try again** button.

The system checks every file. It removes hidden information from photos (such as the camera's GPS location), and refuses files that aren't really photos or PDFs, and PDFs that contain scripts or attachments.

**SVG files can't be uploaded yet.** Save the picture as PNG instead.

## Describe every photo

A photo can't go on the website until it has a **photo description** (for blind visitors and Google). Photos without one show a **Needs a description** badge; the filter **Photos needing a description** lists them, and the Overview counts them.

Select a photo to open its details, then write one sentence about what it shows and select **Save description**. A good description says who or what is in the photo and what is happening, for example "Senior two pupils planting trees beside the library". Don't start with "Photo of".

## Find a file

Use **Search the library** (file name or description), the filters (**Photos**, **PDFs**, **Photos needing a description**) and the grid or list view.

## Replace a file

Open the file and select **Replace with another photo** (or PDF). Every page that uses it shows the new file straight away, and the description stays.

## Remove a file

Open the file. **Used in** lists the pages that use it. A file that is used on the website **can't be moved to Trash**: replace it, or remove it from those pages first. Unused files can be moved to Trash, and restored from Trash for 30 days.
